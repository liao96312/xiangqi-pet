# 象棋 3D 战场周边环境：HY3 独立建模提示词

> 日期：2026-08-12
> 目标：替换当前 `BattlefieldEnvironment.tsx` 的程序化占位几何。下面每一段均是**完整、独立、可单独复制**的提示词，不需要拼接公共模板，也不要一次生成整套场景。

## 一、重新审视后的替换结论

| 优先级 | 当前占位物 | 当前问题 | 应替换成 |
| --- | --- | --- | --- |
| P0 | 圆柱形场地基座 | 像巨大圆饼舞台，没有战场结构 | 夯土点将台 / 石砌护坡平台 |
| P0 | 左侧长方体墙 | 像墓碑或工业方盒，没有砖石、缺口、层次 | 长段残破夯土城墙 A |
| P0 | 右侧长方体墙 | 同样是光滑方盒，左右只改了尺寸 | 短段坍塌城墙 B |
| P0 | 四棱锥营帐 | 像彩色金字塔，没有帐门、骨架、绳索 | 红方 / 黑方汉式军帐 |
| P0 | 平面旗帜 | 像硬纸片，没有厚度、褶皱、旗头和系绳 | 红方 / 黑方军旗 |
| P0 | 单根木桩 | 不是拒马，只像插在地里的铅笔 | 成组木制拒马 |
| P0 | 圆筒 + 发光锥火盆 | 像发光塑料碗，火焰是静态几何 | 青铜行军火盆；火焰由运行时特效负责 |
| P1 | 旋转方块碎石 | 一眼能看出是 box，缺少断面和材质差异 | 夯土砖石瓦砾 / 瓦片焦木瓦砾两组 |
| P1 | 七边圆锥远山 | 像一排低模圆锥，没有山脉轮廓 | 横向远山山脊组 |
| P1 | 完全平整泥地 | 只有颜色噪声，没有车辙、脚印和积水高低差 | 可平铺泥泞战场地形块 |
| P1 | 场景内容偏空 | 缺少军营功能物件和剪影节奏 | 角楼、战鼓、辎重车、兵器架 |

以下两个画面问题**不是建模问题**，不要交给 HY3：

- 棋盘外那块明显发白的半透明大方片：属于 `ContactShadows` / 阴影接收面或混合方式问题，应从渲染代码修复。
- 天空灰糊、远景与地面黏在一起：属于雾、天空、曝光和调色问题，应从灯光 / 后处理修复。

## 二、统一交付规则

- 世界单位按米；`+Y` 朝上，`+Z` 为正面；原点位于资产底部中心，最低接地点为 `Y=0`。
- 每次只生成一个独立资产，不生成整张棋盘、棋子、人物、动物、天空、摄影棚地台或完整微缩景观。
- 写实战争游戏美术，视觉时代统一为汉末三国风格；材质老旧、真实、克制，不做仙侠、奇幻或博物馆新制品。
- 源资产最多一套 2K PBR 贴图：Base Color、Metallic、Roughness、Normal、AO；不得把灯光、阴影、环境色烘焙进 Base Color。
- 适合实时游戏的中模拓扑，轮廓处保留几何，细碎磨损主要进入法线 / 粗糙度；禁止数十万面无效微雕。
- GLB 内不得包含灯光、相机、世界背景、文字对象、隐藏副本和远离主体的漂浮碎片。

## P0-01：中央夯土点将台 / 棋盘承托平台

建议文件名：`battlefield-command-terrace-neutral-v1.glb`

独立提示词：

> 生成一个单独、完整、可用于实时战争游戏的中国汉末三国风格夯土点将台 3D 资产，用于承托一块独立放置的 10×11 米棋盘，但模型本身绝对不要包含棋盘、格线、棋子或文字。整体为低矮的大型矩形军阵平台，外尺寸约 18×19 米，高约 0.55 米；中央必须保留至少 12×13 米连续、平整、无凸起的放置区域。平台不是光滑圆盘：四周由压实夯土、粗糙灰石护坡、零散旧砖收边和两级不完全对称的低台阶构成；边缘有自然塌角、土层断面、雨水冲刷沟、小裂缝和少量嵌入泥土的碎石，但不能破坏中央平面。轮廓厚重、真实、低矮，不要宫殿台基，不要祭坛，不要华丽雕花。材质为潮湿棕灰夯土、旧灰石、少量暗青砖，粗糙度高，只有石头磨损边缘有轻微高光。世界单位按米，+Y 朝上，+Z 为正面，原点位于平台底部中心，最低点 Y=0。实时游戏中模拓扑，建议 25k–45k 三角面，最多一套 2K PBR 贴图，非重叠 UV；不包含灯光、相机、背景和烘焙阴影。禁止圆形舞台、光滑圆饼、棋盘、人物、尸体、武器堆、西式城堡、日式神社、仙侠、卡通、低幼玩具、乐高、夸张龙雕、霓虹、浮空碎片和展示底座。

验收重点：中央必须真的平，四周必须读成夯土与石砌结构，绝不能再像圆饼。

## P0-02：左侧长段残破夯土城墙 A

建议文件名：`battlefield-rammed-wall-long-a-v1.glb`

独立提示词：

> 生成一个单独、完整、可复用的汉末三国中国边塞军营残破夯土城墙 3D 资产，长约 8.5 米、厚约 1.8 米、最高约 3.2 米，用于放在战场棋盘左侧作为近景框景。结构必须明确：夯土墙芯、局部灰砖或毛石包边、残缺的女墙基部、裸露木构加固梁、一个由战损和风化造成的不规则缺口；墙顶高低不齐，断口能看到分层夯土和碎砖，墙脚有少量坍塌土块，但主体仍稳定站立。正反两面都要有真实结构，不得只做正面贴片；轮廓避免规整长方体，端部必须有自然破损和厚度。材质为烟熏棕灰夯土、旧灰砖、深褐风化木，粗糙、蒙尘、有雨痕和少量火烧痕迹，不要大面积纯黑。世界单位按米，+Y 朝上，+Z 为正面，原点位于墙体底部中心，最低接地点 Y=0。实时游戏中模拓扑，建议 20k–35k 三角面，一套 2K PBR 贴图，细碎裂纹进入法线而不是全做几何。禁止光滑方盒、完整宫墙、欧洲城堡垛口、哥特石墙、日式城墙、人物、旗帜、尸体、文字、龙雕、仙侠、卡通、玩具、乐高、展示底座、背景、灯光、相机和漂浮瓦砾。

验收重点：从默认斜俯视仍能看出断口、墙芯层次和顶部轮廓，不能只是贴了纹理的盒子。

## 三、推荐生成与替换顺序

1. 长墙 A、坍塌墙 B：当前画面中最大、最像方盒的两个物体，替换收益最高。
2. 红 / 黑军帐：去掉四个金字塔轮廓。
3. 中央点将台：去掉圆饼舞台感。
4. 红 / 黑军旗、青铜火盆、木制拒马：把近景轮廓做实。
5. 两组瓦砾：解决散落方块的占位感。
6. 远山与泥地：最后统一地平线和地表材质；这两项生成后仍需要 Blender 做尺寸和接缝修整。
7. 角楼、战鼓、辎重车、兵器架：作为高 / 极高画质档的第二批装饰，不阻塞前面替换。

## 四、每个生成结果的最低检查清单

- [ ] 只有一个目标组件，没有棋盘、棋子、人物、背景或摄影棚地台。
- [ ] 正面方向明确，底部落在 `Y=0`，模型没有倾倒、浮空或远处碎片。
- [ ] 不像西式中世纪、日本、仙侠、卡通、乐高或塑料玩具。
- [ ] 轮廓在当前斜俯视和俯视镜头都能读懂。
- [ ] PBR 贴图完整，Base Color 没有烘焙高光和阴影。
- [ ] 面数与贴图预算合理；先保留 2K 源贴图，接入时再按画质档压到 1K / 512。
- [ ] 红黑资产只在布料 / 徽记槽体现阵营，木、土、石、青铜保持自然材质。
- [ ] 导出 GLB 后先单体回读，再替换程序化占位物，不能未经检查直接整批放进战场。
